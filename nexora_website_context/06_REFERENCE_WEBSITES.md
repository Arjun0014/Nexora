# Reference Websites

These are **inspiration references**, not templates.

Claude Design should study the live sites directly where possible.

The goal is to understand what the user liked and decide whether any idea belongs in Nexora.

---

# 1. Arc'teryx — System 0

URL:
https://arcteryx.com/us/en/explore/system0/?ref=siteinspire

## Why it was saved

User described this as a **starter / opening inspiration**.

## Useful observations

System 0 treats the experience as a structured journey rather than a normal corporate landing page.

The live content is organized around a clear system and five steps:
- Find preferred materials
- Design for durability
- Prioritize repairability
- Simplify circular behaviour
- Close the loop

The important reference is not the Arc'teryx content itself.

Study:
- confidence of the opening
- cinematic pacing
- restraint
- chapter-based storytelling
- willingness to let one visual idea dominate the viewport
- how a system can be revealed progressively instead of immediately showing every navigation item

## Possible relevance to Nexora

The Nexora diorama already gives the website a “system” to reveal.

Avoid overcrowding the opening with:
- too many buttons
- stats
- cards
- long paragraphs
- unnecessary navigation UI

# 2. Lambert | Lambert

URL:
https://lambert-lambert.com/?ref=siteinspire

## Why it was saved

Also a **starter / opening inspiration**.

## Useful observations

The site is highly image-led and allows visual material to carry much of the experience.

It uses very little explanatory copy relative to the amount of imagery.

Study:
- visual dominance
- editorial restraint
- spaciousness
- how imagery can lead while typography supports
- premium portfolio-like confidence

## Possible relevance to Nexora

The hero assets are already visually expensive.

Do not bury them beneath normal “corporate website” UI.

The opening can communicate less text and let motion / world-building do more.

# 4. Pinterest zoom / typography transition reference

Original reference:
https://se.pinterest.com/pin/955748352150878388/

The user also supplied the actual video reference separately.

## What the reference does

The useful interaction is a **scale-driven scene transition**.

Pattern:

1. stable scene
2. headline rapidly scales far beyond the viewport
3. background also zooms
4. the composition becomes too oversized / abstract to track
5. the underlying scene swaps while visually masked
6. the incoming visual initially feels softer
7. the new scene settles / sharpens
8. calm state resumes

The oversized typography acts as a transition mask.

## Possible relevance to Nexora

Potential uses:
- exit from the cinematic hero into the standard site
- transition between major editorial chapters
- introduce a Services / Industries section
- create a strong macro transition without using another video effect

Do not repeat this everywhere.

Its strength comes from contrast between:
- calm state
- aggressive transition
- calm state

# 5. Noho

URL:
https://noho.ink/

## Why it was saved

User specifically liked the:

> **pointer multi-use follower**

## Useful observations

The cursor / pointer is treated as a contextual interface element rather than a decorative circle.

The site is also highly motion-oriented and provides:
- dark mode
- reduced animation controls

Study:
- contextual cursor labels
- cursor as a mode indicator
- drag / explore affordances
- playful interaction without adding normal buttons everywhere
- motion accessibility

## Possible relevance to Nexora

A cursor could change contextually to:
- SCROLL
- DRAG
- VIEW
- EXPLORE
- APPLY
- REQUEST

It could also communicate hero progress.

Do not use a custom cursor just because it looks cool.

It should solve an interaction problem.

Disable / adapt it on:
- touch devices
- reduced-motion modes

# 6. LxL Creative

https://www.lxlcreative.co.uk/

## Why it was saved

User specifically liked:

> **Services card swipe like Tinder**

The live site includes an explicit **Drag** interaction and highly visual service / work presentation.

## Useful observations

Study:
- tactile horizontal exploration
- cards as objects rather than static grid boxes
- drag affordance
- visually rich service presentation
- strong image-to-type relationship

## Possible relevance to Nexora

Services or industries could potentially use:
- draggable cards
- swipe / throw interaction
- stacked deck
- active card changes background / supporting content
- Tinder-like interaction language

This is a concept suggestion, not a locked service layout.

If used:
- keep keyboard navigation
- provide normal touch swipe
- avoid making essential information depend on a gimmick

# Overall reference philosophy

Do not create a collage of interactions.

The best lesson across these references is:

> one strong interaction should own one moment.

The site should have rhythm.

Not every section needs:
- cursor effects
- cards
- zoom
- scroll video
- color changes
- huge type

simultaneously.
