# Nexora Website Context Pack

This folder is the handoff context for designing and building the new **Nexora Hospitality and Services W.L.L.** website.

## How to use this pack

Read the files in order before making design or implementation decisions.

The most important distinction is:

- **The hero experience is largely decided and should be treated as a locked creative direction.**
- **The rest of the website is intentionally not designed yet.**
- The reference sites and interaction ideas are **inspiration**, not a checklist.
- Claude Design / Astra should decide the overall information architecture, section order, page structure, visual system, and which interaction ideas are worth using.
- Claude Code should implement the approved design without inventing business claims.

## Important rule

Do not copy the competitor or inspiration websites.

Use them to understand:
- pacing
- interaction language
- content hierarchy
- visual confidence
- motion patterns
- ways of presenting services

Nexora should feel like its own premium GCC workforce brand.
