# Content Requirements

Claude Design should decide the actual site structure.

This file defines what the website needs to communicate, not the section order.

---

# Core questions the website must answer

A visitor should quickly understand:

1. What is Nexora?
2. What kind of workforce / services can Nexora provide?
3. Which sectors can it support?
4. Why should a business contact Nexora?
5. How does workforce engagement / deployment work?
6. How can an employer submit a requirement?
7. How can a candidate apply / register?
8. How can someone contact the company?

## Industries

- Facilities

## Process

## Why Nexora / trust
Because there are no confirmed public stats yet, this should focus on capability principles rather than fake numbers.

Potential themes:

- sector-aware workforce
- service standards
- coordination
- screening
- quality mindset
- human support

Do not claim verification, certifications, turnaround guarantees, or compliance systems without confirmation.

# Potential site models

Claude Design should choose.

## Model A — premium single-page experience
Hero + carefully selected content + conversion.

## Model B — cinematic homepage + functional subpages
Homepage tells the brand story.
Subpages handle:
- Services
- Industries
- Careers
- Contact

## Model C — hybrid
Homepage contains core story and service summary.
Deep pages only for high-value content.

No model is currently locked.
