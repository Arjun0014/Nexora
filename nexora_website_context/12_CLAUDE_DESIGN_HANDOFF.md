# Claude Design Handoff

## Mission

Design the complete Nexora website using the context in this folder.

The cinematic hero has already been substantially designed.

Your main responsibility is to decide what the **rest of the website should become**, while ensuring the hero and the remaining site feel like one coherent experience.

## What is expected from Claude Design

Decide:

- information architecture
- whether this is one page or multi-page
- homepage section structure
- what content deserves dedicated pages
- navigation
- post-hero visual language
- typography
- spacing / grid
- service presentation
- industry presentation
- employer conversion flow
- candidate conversion flow
- hero exit
- where interaction ideas belong
- which reference ideas should NOT be used

Do not ask the user to design the site for you.

Use design judgment.

---

## Hero handling

Treat the five-world diorama / time-freeze experience as the primary creative anchor.

You may refine:
- copy
- progress UI
- typography
- hero exit
- responsive adaptation

Do not replace the hero concept.

---

## Reference handling

The reference sites are not a checklist.

Avoid:
- copying layouts
- stacking every effect
- creating an awards-site interaction demo with weak business communication

The website still needs to convert employers and candidates.

---

## Business guardrails

- workforce solutions first
- hospitality is important
- construction excluded
- no fake statistics
- no fake clients
- no fake projects
- no fake certifications
- no fake testimonials
- no unsupported “leading” claims

Where factual content is missing, design the module with placeholders or write claim-safe copy.

---

## Quality target

The site should feel like a modern premium GCC business with unusually strong art direction.

It should be:
- memorable
- cinematic
- sophisticated
- fast enough to use
- clear about the business
- conversion-oriented
- restrained where restraint improves the experience

It should not feel like:
- a generic manpower template
- an AI website
- an overanimated experiment
- a construction company
